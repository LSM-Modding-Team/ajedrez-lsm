# Trabajo en este repositorio

- Trabaja y pushea directamente en la única rama existente (`main`).
- No crees ramas adicionales ni pull requests, salvo que el usuario cambie esta instrucción.
- Conserva la estética aprobada y las reglas del torneo al actualizar documentación.
- Los datos de demostración solo se usan en capturas, nunca se precargan en el sitio publicado.
- Después de modificar los archivos compartidos de CSS o JS, ejecuta `python scripts/build_pages.py` para actualizar las páginas y su caché. Conserva el contenido fuera de los bloques marcados.
